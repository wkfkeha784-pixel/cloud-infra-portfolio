### 사용자가 나중에 처리할 항목

- **과거 Git·PR 이력의 전화번호 흔적 정리 — 사용자 요청으로 보류.** 현재 공개 소스의 실제 번호는 제거했지만 과거 이력까지 완전히 삭제한 상태는 아닙니다. 사용자는 나중에 처리하기로 했습니다. 이 기록을 완료 표시로 바꾸거나 이력 재작성·저장소 삭제·공개 범위 변경을 자동 실행하지 않습니다. 사용자가 재개하면 기존 배포·지원서 링크를 확인한 뒤 필요한 정리 방법을 구체화합니다.
- **GitHub 보조 문서 보기의 503 — 접속 상태 확인 항목.** 사용자가 직접 해야 하는 계정 설정 작업은 아닙니다. 마지막 재확인에서 프로필 소개 기록은 200으로 회복됐고, 시각화 가이드 보기에서만 503이 남았습니다. API에서 확인한 원본 존재와 문서 보기 응답을 구분합니다.
