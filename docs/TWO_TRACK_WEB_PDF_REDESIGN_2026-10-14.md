## 목표와 공통 사실 기준

- **웹 (Evidence Library):** 면접관·현업 심사자가 프로젝트별 문제·역할·검증 조건·시점·공개 근거를 탐색하는 상세 공간. 공개주소 `https://cloud-infra-portfolio.vercel.app/`.
- **PDF (Recruiter Brief):** 채용담당자가 약 30초에 직무·개인 기여·대표 결과를 파악하고 필요하면 웹으로 이동하는 회사 공통 요약 자료. **현재 외부에 제출된 기존 PDF와 구분**한다.
- **공통 진실원천:** `src/data/projects.ts`, `src/data/*Reading.ts`, 실제 제출 PDF 2026-10-14 버전과 개인 프로젝트 원장. **[MY]·[PROJECT]·[OPEN], 단발성 시험, PoC/제안, 테스트 시점, 경력/교육 경계 유지**.
- **변경 금지:** 서버·DB·모니터링 자동화 등 타인 작업을 [MY]로 표시하지 않는다. HTTP 300/300을 DB 300건 기록으로, Bluebell 통제 시험을 완전 자동 트리거 검증으로, worker-03 단일 노드 재가입을 전체 클러스터 복구로, OneReport 규칙 기반 분석을 LLM 구현으로, Labbit 코드·CI를 실 VM E2E 완료로 표현하지 않는다.
- **공개 범위:** 공개 웹에 전화번호·증명서 원본·비공개 팀 저장소 URL·실물 이력서 PDF를 추가하지 않는다.

### 검증한 범위와 향후 검토

- 생성 PDF **10쪽** 정상; 한글 텍스트 추출 가능; 슬라이드 전체 이미지 렌더링 및 2개의 웹/GitHub 링크 유지.
- **시안임:** 기존 13쪽의 모든 세부 수치·시험 스냅샷이 그대로 들어간 완전한 기술 부록은 아니다. 핵심 내용만 편집/재배치했으며 웹에 남은 상세 근거와 의도적으로 역할 분담.
- 텍스트 기반 1차 근거 검토 후 **시각적 위계·개인 역할·도표 읽기**에 집중해 발전시킨다. 사외 공식 제출 기준선을 바꾸려면 사용자의 최종 승인과 PDF 전체 재검토가 필요하다.
- 편집용 발표자료의 폰트 유무에 따라 다른 기기에서 치환될 수 있다. 출력본 PDF를 별도로 검증한다.
