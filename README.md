# Cloud Infrastructure Portfolio

박희철의 회사 제출용 PDF Portfolio를 보완하는 공개 Web Portfolio입니다.

## 목적

- PDF: 회사 지원 시 제출하는 핵심 요약본
- Web: 프로젝트 Case Study
- GitHub: 코드, PR, 테스트, Evidence 원본

## Stack

- React
- TypeScript
- Vite
- React Router
- Static deployment

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Structure

```text
src/
├─ components/
├─ data/
│  └─ projects.ts
├─ pages/
├─ styles/
├─ App.tsx
└─ main.tsx
```

## Public contact policy

공개 Web에는 Email과 GitHub만 노출하며 전화번호는 표시하지 않습니다.

> 공개 Web에는 전화번호가 포함된 회사 제출용 PDF를 직접 게시하지 않습니다.
